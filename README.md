# 🔹 4. StyleGen – README


# StyleGen

StyleGen is an AI-based styling and design generator that helps users create fashion or visual style ideas based on inputs.

## Features

- AI-generated style suggestions  
- User input-based customization  
- Clean and interactive UI  
- Fast generation system  

## Tech Stack

- Frontend: React.js  
- Backend: Node.js  
- AI Integration: Pexel API  

## Setup Instructions

### 1️. Clone the repository

```
git clone https://github.com/sparsh1606/StyleGen.git
cd task-manager
```

---

### 2️. Backend Setup

```
cd Backend
npm install
node app.js
```


---

### 3️. Frontend Setup

```
cd Frontend
npm install
npm run dev
```
