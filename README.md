# 🔹 4. StyleGen – README


# StyleGen

StyleGen is an AI-based styling and design generator that helps users create fashion or visual style ideas based on inputs.

## Features

- AI-generated style suggestions  
- User input-based customization  
- Clean and interactive UI  
- Fast generation system  

## Tech Stack

- Frontend: React.js  
- Backend: Node.js  
- AI Integration: Image/Text generation API  

## Setup Instructions

### 1️. Clone the repository

```
git clone <your-repo-link>
cd task-manager
```

---

### 2️. Backend Setup

```
cd backend
npm install
node server.js
```


---

### 3️. Frontend Setup

```
cd frontend
npm install
npm run dev
```
